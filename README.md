# sgx-phone-hud

星光事務所小手機 HUD 的**遠端通道**託管倉。

## 目前快照

- `main`：HUD／loader **2.24.6**，同步自星光事務所 v1.0 加批七中段成品，不是正式驗收版。
- 本次只更新 `dist/hud.js` 與 `dist/phone.js`，不包含整卡 JSON、作者來源、聊天存檔或使用者設定。
- 來源整卡 SHA256：`b9baac60ded73430e44481ca53bff5fb67955c5ed051619e9858549bb2ed2e75`。
- 已驗：靜態校驗、兩支 dist 腳本語法、行文語言 3 案、專業面向成品 9 案、隔離 Chromium 介面切換 9 案。本次介面回歸通過，但先前偶發能力條尺寸斷言仍待定位；其餘整包回歸及真實酒館驗收尚未完成。
- 卡內 loader 目前釘 `v1.0`，**不是 `main`**；本次未建立或移動 tag，也未更改卡內載入地址。只推 `main` 不會令既有卡片自動載入此快照。
- 推送前遠端尚無 `v1.0` tag；該通道不可用時依既有邏輯降級至卡內備援。較舊遠端 HUD 亦不得覆蓋較新的卡內版本。

## 這是什麼

娛樂圈卡(星光事務所)的小手機介面採「卡內烘焙備援＋遠端通道」雙軌:

- 卡片本體永遠自包含,內建一份烘焙好的 HUD(離線、嚴格環境、分享情境都能跑)
- loader 啟動時嘗試從本倉 `dist/hud.js` 載入較新版本(jsdelivr CDN);成功跑遠端版,失敗大聲降級回卡內版

## 換版紀律

- **釘 tag,不釘 branch**:loader 指向 `...@vX.Y.Z/dist/hud.js`
- 換版 = 刻意事件:推新版 → 打 tag → 手動改 loader 釘的版本字串
- tag 與卡片 phone.js 版本對齊(如 `v2.14.0`)

## 來源與所有權

- 唯一真源在卡片 repo 的 `卡片/來源/scripts/phone/`;本倉 `dist/` 是構建產物,**不直接手改**
- 內容為介面程式碼,零敏感資料;無人設文字

## 降級紅線

遠端載入失敗時,小手機必須**可見地**降級回卡內烘焙版(狀態標記 BAKED),不允許靜默黑屏。
